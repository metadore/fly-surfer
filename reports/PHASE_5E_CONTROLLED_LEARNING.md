- Eligibility is delay-matched: a tag is created only when a presynaptic packet is delivered in the same step as the postsynaptic spike. There is no coincidence window.
- Evaluation uses eta = 0 on the current learned state, the same evaluation episodes at every checkpoint, and traces disabled.
- Train and evaluation seeds are drawn from separate SeedSequence streams before the experiment. Disjoint: `True`; overlap count `0`.

- Reward is an external scalar in task units; no dopamine, octopamine or serotonin quantity was measured.
- A weight change is a model output of the declared three-factor rule; it is not evidence of biological synaptic plasticity.
- The eligibility rule has no coincidence window: a tag exists only when a delayed presynaptic packet arrives in the same step as the postsynaptic spike. Learning therefore depends on precise spike timing.
- Success is measured only for the designated response population; the selective (competition) metric is reported separately and is not the primary criterion.
- Three replicates give a descriptive mean and standard deviation; no formal significance claim is made in Phase 5E.
- The conventional baseline receives the correct action label and only bounds what a supervised method can do on this task.
- Evaluation uses the same held-out episodes at each checkpoint; it does not test generalisation to unseen cue mappings.
- The synthetic graph is small (tens of nodes); nothing here tests the BANC connectome.
- Action selection (the first action population to spike) remained near or below the four-action chance rate; this task measures a conditioned response, not competitive action selection.
- Condition E's Bernoulli(0.5) wiring has fewer edges and lower total cue input than the complete graph (67 vs 128 edges), so its impaired response cannot be attributed to topology alone.
- The predeclared 0.75 success / 20-episode criterion was met by the fixed-weight control A without any weight change, so the criterion does not discriminate learning on this task; the held-out evaluation is the evidence used.
