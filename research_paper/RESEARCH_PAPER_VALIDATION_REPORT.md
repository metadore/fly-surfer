## 12. Unresolved documentation issues

1. **Figure discussion order versus list order.** Figure numbers were assigned by topic and then preserved through the +6 shift, so the numbering is gapless 1–39 and every reference matches its image. The order in which figures are *discussed* still differs from numeric order in a few places: Chapter 3 discusses Figure 8 before Chapter 5's Figures 9–14, Figure 16 is mentioned before Figure 17, and Figures 6–7 are discussed after Chapter 5's figures. This is because later chapters forward-reference dataset and detector figures. The difference is cosmetic: the generated list of figures is built by `assemble.py`, which sorts by figure number, so the list runs 1–39 in numeric order and does not follow document order. No renumbering was needed for the list.
2. **Page 4 is nearly empty.** The scope statement on the title page forces a page break before the abstract; the residual whitespace is a layout consequence, not a missing section.
3. **`docs/PHASE_8_EXECUTION_COMMANDS.md` is stale.** It was written before execution and still describes the pre-execution state of the run commands; the paper cites it as a historical preparation document and does not reproduce its contents as commands to be run.
4. **The register and this report exist only as Markdown.** They are companion documents to the paper, not chapters of it, and are not embedded in the DOCX.
5. **Word count differs by tool.** Word reports 66,010 words for the rendered DOCX; a naive whitespace token count of the Markdown source is larger because it includes table pipes, markup, and field text. The Word figure is the one quoted in §2.
6. **The DOCX grew to 23.8 MB.** The six YOLO11n figures are rendered at 2023–3476 px wide (~20 MB total) so that class names and confidences stay legible in print. They were deliberately not downsampled after visual verification; the PDF is unaffected in size because it compresses the images.
7. **The labels are loose.** Annotation boxes in the source dataset are visibly larger than the objects in several images and occasionally clip a neighbouring object. Figure 10 shows this as recorded; the boxes were not tightened or corrected, because doing so would misrepresent the label files the deployed detector was trained and evaluated against.
