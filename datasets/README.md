## Pre-connectome recommendations

1. Build adjacency on **directed pairs**, summing `syn_count` across neuropils; do not treat rows as separate edges.
2. Apply the ≥5 threshold once at pair level. The filtered table already encodes it; aggregate the unfiltered table before thresholding.
3. Keep all 139,255 neurons as nodes, including 139 absent from unfiltered and 671 absent from filtered connections.
4. Deduplicate coordinates at exact-row level, then choose one documented position per neuron (centroid or principal position).
5. Handle the 19,658 neurons without `nt_type` with a documented fallback; do not drop them.
6. Treat FAFB as brain-only; add BANC or Male CNS before claiming a complete brain-to-motor pathway.

## Repository data policy

This repository tracks the **derived** connectome artifacts and the small
research outputs needed to run and audit the simulation. It does not track the
original FlyWire downloads. The raw files remain in `datasets/raw/` and are
excluded by `.gitignore` (`datasets/raw/**`); they are not deleted, moved,
recompressed, renamed or modified by this repository.

### Reproducing the connectome

From the repository root, with the raw files in place:

```bash
# 1. Audit all 15 raw files and write datasets/manifest.json + this audit file
python dataset_audit.py

# 2. Rebuild the processed artifact and run the round-trip checks
python -m brain.connectome_loader

# 3. Verify artifact compatibility and the simulation test suite
python -m pytest -q
```

`brain.connectome_loader` builds nodes in ascending `root_id` order, sums
`syn_count` across neuropils for each directed pair, and applies the >=5
synapse threshold **once at pair level** (never per row). Its default outputs
are the three files in `datasets/processed/`; use `--help` for `--out`,
`--nodes-out`, `--report`, `--threshold`, `--chunksize` and `--no-verify`.
The expected totals are 139,255 neurons, 3,732,460 edges and 50,666,648 summed
synapses.

### Why raw data is excluded from Git

- The 15 raw files total 352 MiB compressed and include a 263 MiB unfiltered
  table that the simulation never reads.
- They are immutable third-party research data whose use is governed by the
  FlyWire release terms, not by this project's source licence.
- Git LFS would add bandwidth and storage quotas without improving
  reproducibility, because the derived artifact is small enough to track
  directly and the raw files can be re-downloaded and checksum-verified.
- The four incomplete `.crdownload` files listed above, the raw synapse
  table and raw skeleton archives were never processed. They are left
  untouched and are excluded by the `*.crdownload` and `datasets/raw/**`
  rules.
